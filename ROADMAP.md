# Roadmap

[README](README.md) · [Testing and accuracy](docs/testing.md)

The desktop frontend, cartridge save media, BIOS boot, save states and native release packaging are in place. The remaining work focuses on emulation accuracy and coverage.

- Validate Swan Revival link play against MesenCE with retail games on separate computers.
- Review LCD off-state and indicator behaviour against hardware.
- Continue comparing game output with Swanium and investigate functional differences in graphics, audio and input.
- Extend interactive testing on Windows and Linux, including physical controllers and native file pickers.

The [regression baselines](docs/testing.md#regression-suite) document the current coverage. Earlier milestone and session records are available in Git history.
